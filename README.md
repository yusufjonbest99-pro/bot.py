# 🤖 Telegram Video Downloader Bot

✨ Бот скачивает видео по ссылкам (TikTok, Instagram, YouTube)

## 📌 Возможности:
- Проверка подписки на канал
- Ограничение: 4 видео в день
- Поддержка ссылок
- Автоматическая отправка видео

## 📢 Канал:
https://t.me/infocenterpro

## ⚙️ Использование:
1. Подпишитесь на канал  
2. Отправьте ссылку на видео  
3. Получите скачанное видео  

⛔ Без подписки видео не отправляется
